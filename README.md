## 🚀 GitHub Pages Setup

To enable or verify the live link on GitHub:

1. Open repository **Settings** &rarr; **Pages** (under *Code, planning, and automation*).
2. Under **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main` / folder: `/(root)`
3. Click **Save**.
4. GitHub will publish your site at:  
   👉 **`https://tycoonvikas.github.io/priv/`**
